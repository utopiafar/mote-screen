# mote-screen

菜单栏里只看连接状态。速度和 Codex 待处理画在 3.97 寸墨水屏上。

这套仓库里有四块东西：

- `core/`：状态、hook 合并、协议和刷新策略。模拟器和测试用的是这一份。
- `simulator/`：浏览器里走同一套状态机，不需要真机。
- `apps/mac/`：macOS 菜单栏客户端。Linux 上编不过，这是预期的。
- `firmware/`：ESP32-S3 上的自制固件。只编译，不烧录。

## 三项可以改的设置

都在 Mac 的「设置 → 墨水屏」，模拟器同一页也能改。墨水屏自己的设置页会显示当前的连接方式和刷新策略。

**连接方式。** 默认 Wi-Fi。也可以选蓝牙。蓝牙是这块自制固件上的通道，不是出厂 Dolphink 系统里已经在用的功能。USB 是「插入时自动用 USB」：插着选定的串口时改走串口，不会把上面选的 Wi-Fi 或蓝牙关掉。这台 Mac 上可能有不止一个 ESP32 串口，选错端口没有画面。

**通信频率。** 这是 Mac 多久推一次状态，和屏幕多久刷新不是一回事。Codex 的批准请求和一轮结束会立刻推，不等间隔。速度按间隔推。预设「省电 / 均衡 / 及时」会一起改通信和刷新，下面仍可以单独改。默认是均衡：生成中约 15 秒，空闲约 1 分钟。

**墨水屏刷新。** 开机先做一次基线，把同一幅 1-bit 画面写进新旧两块显存，这一下可能会闪。之后换页，以及同一页上的数字、时钟和卡片，都走不闪的局部刷新，只更新和上一幅不一样的点。每隔若干次局部刷新，或每隔几分钟，再做一次基线清残影，这时可能会闪一下，但不会每次换页都闪。默认大约每 10 次，或者每 10 分钟。局部更快更省电；基线更干净，也更费电。默认按 1200 mAh、Wi-Fi 仍可能开着来留余量。这里只用微雪公开的 1-bit 基线和局部命令，不用 4 灰阶，也不新增寄存器。

菜单栏状态只有四个词：设置中、未连接、已连接、Hook 失效。跳过墨水屏之后是未连接。

## 模拟器

在仓库根目录：

```bash
node simulator/serve.mjs
```

打开 http://127.0.0.1:4173/simulator/index.html 。底部可以切换安装阶段、注入批准或结束、推进时间、插拔 USB。正式截图可以加 `?chrome=0` 或 `?shot=1` 把这条栏藏起来。

没有 Node 时，在仓库根目录起一个静态服务，然后打开 `/simulator/index.html` 也行。页面是 ES module，需要通过 http 打开，不要直接双击文件。

## 测试

```bash
node --test
make -C firmware/host test
```

第一组覆盖菜单状态、hook 只追加和只删除自己的条目、协议、三项设置、设备按键。第二组用 gcc 跑同一套逻辑，并画一帧界面确认有墨。

## Mac 客户端

在 macOS 14 或更新的系统上：

```bash
apps/mac/scripts/assemble-app.sh
```

得到 `连接状态.app`。它只在菜单栏显示连接状态。窗口标题只有「开始设置」和「设置」。

Hook 写在用户目录的 `~/.codex/hooks.json`，只追加 `PermissionRequest` 和 `Stop`，不覆盖别的 hook。脚本在应用数据目录里，收到事件后只把一句摘要发到本机 `127.0.0.1:7428`。清理只会删我们自己的条目和脚本，然后退出，剩下的由你把应用丢进废纸篓。

## 固件

目标板是微雪 ESP32-S3-ePaper-3.97（16MB 闪存，8MB PSRAM，480×800 的界面）。面板可以做四灰阶，v1 界面按 1-bit 送。引脚和初始化命令来自微雪公开的 ESP-IDF 示例和原理图，见 `firmware/components/epd/`。

编译（不会烧录）。第一次编译会从乐鑫组件库取 `espressif/mdns`，因为 ESP-IDF 5.5 里这份 mDNS 不再随内核发布。

```bash
idf.py -C firmware build
```

或者：

```bash
docker run --rm -v "$PWD:/work" -w /work espressif/idf:v5.5 idf.py -C firmware build
```

烧录方式以乐鑫和微雪的 ESP-IDF 文档为准。这个仓库不提供烧录命令，也不会去刷你的设备。

固件同时听三路同一份 NDJSON：Wi-Fi TCP `7427`、我们自己的 BLE GATT、以及 USB Serial/JTAG。收到第一份 `config` 之后，没被选中的无线电可以停下来省电。USB 口一直可以收帧。Wi-Fi 口令只从 USB 上的 `wifi` 帧写入 NVS，不进仓库、不进日志。

界面字库是常用字的一小份，按 24 / 36 / 56 / 96 四档做成 1-bit 粗体，避免小字在四灰阶上发糊。模拟器使用同一套字号和纯黑字。固件上没进字库的标题会空一格。

屏幕物理方向在代码里按「竖着看」做了旋转，没有在真机上核对过。
