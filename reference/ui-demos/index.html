主桌面进工作台，上面是速度，下面是待处理

首页是带多格的主桌面，工作台只是其中一格。点进去后，第一屏按方案 B 来：上半是 token 速度，下半是需要处理的大卡。再按进去，才是速度详情和完整收件箱。时钟、设置是为了把桌面撑起来的示意入口，预留格这一期不开放。数字仍是示意数据。

滚轮
按键

也可以直接打开 device.html。键盘：方向键选择，回车打开，Esc 当作 BOOT，会先回到工作台，再回到桌面。

怎么交互

  • 主桌面四格：工作台、时钟、设置、预留。滚轮移动选中，按下进入。
  • 进入工作台后，滚轮先选上半的速度，再选下面的卡片。按下一格进速度详情，按下一张卡进完整收件箱。
  • BOOT 从详情回到工作台，再按一次回到主桌面。
  • 收件箱只放 Codex。速度仍是 Agent Speed 的全机数据，所以详情里可能看到其他来源的 tok/s。

键盘：↑ ↓ 选择 · Enter 打开 · Esc 返回

在预览里注入事件

用来看工作台和首页数字怎么刷新，不必刷机。

看 Mac 客户端长什么样 只负责连接状态。第一次打开会走设置向导：接 Agent Speed、装 Codex hook，墨水屏可先跳过。设置和调试收在同一个窗口，左边用 Tab 切换；hook 出问题可以重新安装，卸载前也能清理。
